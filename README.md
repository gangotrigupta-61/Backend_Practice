# Node.js Basics Practice

This project contains a simple Node.js program that demonstrates:

- A `for` loop that prints greetings from 0 to 4
- The built-in `process` object
- Reading command-line arguments with `process.argv`

## Run the program

```bash
node nodebasics.js
```

To pass names or other arguments:

```bash
node nodebasics.js Alice Bob
```

The program prints a greeting for each argument. The `MODULE.EXPORTS` section is reserved for practicing how to export code from a Node.js module.
