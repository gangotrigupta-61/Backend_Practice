# Backend Practice Repository

This repository is a collection of backend learning exercises focused on Node.js and Express. It covers the basics of server-side development and how JavaScript can be used to build web applications.

## What has been studied

- Node.js fundamentals
  - running JavaScript in Node
  - using process and process.argv
  - loops, console output, and basic scripts
  - modules and exporting/importing logic with require and module.exports

- JavaScript OOP concepts
  - factory functions
  - constructor functions
  - prototype-based programming
  - ES6 classes
  - inheritance

- Express.js basics
  - creating a server
  - handling GET and POST requests
  - route parameters and query strings
  - sending responses and rendering text/HTML

- Templating with EJS
  - creating dynamic pages
  - passing data from server to view
  - rendering conditionally and serving static files

- REST API concepts
  - CRUD operations using routes
  - reading request body data
  - updating and deleting records
  - using UUIDs and method override

- Data handling
  - JSON data usage
  - arrays of objects
  - rendering posts/content from server-side data

## Project structure

- Node basics: nodebasics.js, apple.js, banana.js, orange.js, index.js
- Express practice: Express_Basic/
- Templating practice: Templating/
- REST API practice: REST/
- OOP practice: OOPS/

## Main learning outcome

The repo demonstrates the transition from basic JavaScript/Node knowledge to building server-based web apps using Express, dynamic views, and REST-style APIs.
